# Thirukural Explainer Web App

A bilingual interactive web application combining classical Thirukkural verses with historical 1886 G.U. Pope English translations and Gemini AI-generated short-story explanations, presented in a classical oil-paint glassmorphism aesthetic.

---

## Features

- **Complete Verse Dataset**: Preloaded in-memory dataset of all 1,330 Thirukkural verses with original Tamil text and G.U. Pope's 1886 poetic translations and prose meanings.
- **Bilingual Interface**: Seamlessly switch between English and Tamil (தமிழ்) with instant UI adaptation.
- **Multi-Mode Search**: Search by exact kural number (1–1330), starting words of a verse, or Athigaram number (e.g., `adhigaram 5`).
- **No-Dead-End Discovery**: Recommends randomized famous kurals when a search query finds no match.
- **Vertical Stack Reading Layout**: Prominent sacred verse in distinct classical Tamil typography, followed by authoritative G.U. Pope translations and Tamil commentary.
- **AI Short-Story Explanations**: Contextual 2-to-3 paragraph real-world stories generated by Google Gemini 2.5 Flash illustrating the moral wisdom of each couplet.
- **Trivia Loading Screen**: An engaging overlay displaying rotating cultural "Did you know?" facts about Thiruvalluvar and the Thirukkural during story generation.
- **In-Memory Caching**: Generates stories on demand and caches them in a session dictionary for sub-millisecond repeat views.

---

## Tech Stack

- **Backend**: FastAPI (Python 3.10+)
- **Server**: Uvicorn ASGI
- **AI SDK**: Google GenAI SDK (`gemini-2.5-flash`)
- **Frontend**: HTML5, CSS3 (Glassmorphism & Oil-Paint Theme), Vanilla JavaScript
- **Dataset**: Curated local JSON (`app/data/thirukkural.json`)

## Quickstart

### 1. Clone & Install Dependencies
```bash
git clone <your-repo-url>
cd Build_with_basic
pip install -r requirements.txt
```

### 2. Configure Environment Variables
Copy the example environment template:
```bash
cp .env.example .env
```
Open `.env` and add your Google Gemini API key:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: If no API key is provided, the application runs in offline mode using pre-built contextual stories).*

### 3. Run the Development Server
```bash
uvicorn app.main:app --reload --port 8000
```

Open your browser to:
- **Application UI**: [http://localhost:8000](http://localhost:8000)
- **Interactive API Documentation (Swagger)**: [http://localhost:8000/docs](http://localhost:8000/docs)
