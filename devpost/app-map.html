Thirukural Explainer — App Map & Architecture Guide

A permanent reference map for understanding how the backend, data, and AI layers connect.

🧭 App Purpose and Structure

The Thirukural Explainer is a single-environment Python web application built with FastAPI. It loads 1,330 Thirukkural verses into memory alongside historical G.U. Pope translations (1886) and uses Google Gemini 2.5 Flash to generate real-world short stories that illustrate the moral wisdom of each couplet.

🔄 Core Data Flow: Requesting a Verse & Story

Here is what happens when someone searches for a kural and clicks "Generate Story Illustration":

[ User Browser ] │ ▼ 1. Clicks "Generate Story Illustration" [ app/static/app.js: triggerStoryGeneration(1) ] │ ├── Activates Trivia Loading Overlay (cycles cultural facts) │ ▼ 2. HTTP GET /api/kural/1/story?lang=en [ app/main.py: @app.get("/api/kural/{number}/story") ] │ ▼ 3. Checks In-Memory Cache Dictionary [ app/ai.py: STORY_CACHE.get("1_en") ] │ ├── Cache Hit? ──▶ Returns story in <1ms (source: "in-memory-cache") │ └── Cache Miss? │ ├── Formats structured bilingual prompt with G.U. Pope text ├── Calls Google Gemini API (gemini-2.5-flash) ├── Saves result into STORY_CACHE["1_en"] └── Returns JSON { kural_number: 1, story: "...", cached: false } │ ▼ 4. DOM Update [ app/static/app.js ] ──▶ Hides Trivia Overlay ──▶ Renders Story in Vertical Stack

🗺️ 3 Core Code Locations

Stop 1: FastAPI Application Router

File: app/main.py

Contains endpoint routing for verse search, lookup, and story generation. Notice how specific endpoints like /api/kural/search are registered before parameterized routes like /api/kural/{number} so strings aren't parsed as integer paths.

Stop 2: AI Prompt Engine & In-Memory Cache

File: app/ai.py

Implements generate_kural_story() and STORY_CACHE. It injects the verse's Tamil text and G.U. Pope commentary into a contextual prompt template and caches results per session.

Stop 3: Frontend Vertical Stack Controller

File: app/static/app.js

Controls language switching (English/Tamil), search execution, sequential next-kural navigation, and manages the cultural "Did you know?" trivia overlay during generation latency.

🛠️ To Change This, Start Here

  • To customize the AI story prompt: Open app/ai.py and edit craft_prompt() to adjust the story length, tone, or setting.
  • To add or edit "Did you know?" trivia facts: Open app/trivia.py and append new items to TRIVIA_FACTS.
  • To adjust the oil-paint colors or glassmorphism blur: Open app/static/style.css and tweak CSS custom properties under :root.
  • To change the fallback famous kurals: Open app/data.py and edit FAMOUS_KURAL_NUMBERS.

💡 A Practice to Reuse

1. Strict Route Ordering in Backend Frameworks: In FastAPI, routes evaluate in the order they are defined. Always register literal endpoints (/search, /famous) before dynamic wildcard paths (/{number}) to prevent type validation conflicts.

2. Engaging Latency Transformation: Instead of showing a blank, boring loading spinner during LLM inference, presenting lightweight cultural trivia ("Did you know?" facts) turns latency into an enriching user experience.

▶️ How to Run the App

Start the server from your terminal anytime with:

uvicorn app.main:app --reload --port 8000

Open http://localhost:8000 in your browser.
